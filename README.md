# YouTube Playlist Automation

Autonomous YouTube backlog triage and calendar scheduling pipeline.

## Overview
Turns unstructured video backlogs (custom intake playlist / exports) into structured, energy-aware calendar viewing blocks via automated extraction, LLM classification, and calendar slotting.
